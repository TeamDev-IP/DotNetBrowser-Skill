### Interfaces

 [IEvent](DotNetBrowser.Dom.Events.IEvent.md)

Represents DOM <code>Event</code> object and provides access to the event object data.

This interface is implemented by all <xref href="DotNetBrowser.Dom.INode" data-throw-if-not-resolved="false"></xref> implementations

 [IEvents](DotNetBrowser.Dom.Events.IEvents.md)

A collection of custom DOM events that can be listened and/or handled.

 [IKeyEvent](DotNetBrowser.Dom.Events.IKeyEvent.md)

Represents a keyboard event and provides an access to specific keyboard event data.

<p>
    This event occurs when a user performs some keyboard action, for example presses or releases a
    keyboard key.
</p>

 [IMouseEvent](DotNetBrowser.Dom.Events.IMouseEvent.md)

Represents a mouse event and provides an access to specific mouse event data.

<p>
    This event occurs when a user performs an action with a pointing device (such as a mouse), for
    example moves the mouse or clicks a mouse button.
</p>

 [ITouchEvent](DotNetBrowser.Dom.Events.ITouchEvent.md)

Represents a touch event and provides an access to specific touch event data.

<p>
    This event occurs when a user performs an action with a touch device (such as a touchscreen).
</p>

 [IUiKeyEventModifier](DotNetBrowser.Dom.Events.IUiKeyEventModifier.md)

Represents a DOM UI event that can be fired with the key modifiers.

<p>
    The <xref href="DotNetBrowser.Dom.Events.IUiKeyEventModifier.KeyModifiers" data-throw-if-not-resolved="false"></xref> provides access to the data about pressed service keys, such as
    <code>Ctrl</code>, <code>Alt</code>, <code>Shift</code>, <code>Meta</code>,
    when a keyboard or mouse event occurs.
</p>

 [IWheelEvent](DotNetBrowser.Dom.Events.IWheelEvent.md)

A wheel event that provides access to the wheel event data.

<p>This event occurs when a user rotates a wheel on a pointing device (such as a mouse).</p>
