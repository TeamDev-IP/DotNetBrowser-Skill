Version 4.4.1 · Posted on 2026-11-10

## Chromium 157.0.8103.51

We upgraded Chromium to a newer version, which introduces 9 security fixes.
Among them:

* [CVE-2026-125345: Uninitialized resource in WebGL][cve-2026-125345]
* [CVE-2026-125347: Incorrect authorization in FileSystem][cve-2026-125347]
* [CVE-2026-125343: Buffer overflow in Compositing][cve-2026-125343]
* [CVE-2026-125348: Out of bounds write in GPU][cve-2026-125348]
* [CVE-2026-125344: Type confusion in V8][cve-2026-125344]

See the Chromium [release announcement][chromium-nov-9-2026] for more
details.
